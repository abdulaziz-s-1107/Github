# Do'kon plani dasturi

Do'konning planini (xaritasini) ko'rsatadigan dastur. Planda har bir qurilma va jihoz qayerda turgani belgilangan. Qurilmani bir marta bossangiz, uning ma'lumotlari animatsiya bilan ochiladi.

## Holati

Loyiha endi boshlanmoqda. Hozircha kod yo'q.

## Rejalashtirilgan imkoniyatlar

- Do'kon planini rasm sifatida ko'rsatish
- Planda qurilmalarning joylashuvini belgilash
- Qurilma bosilganda uning ma'lumotlarini animatsiya bilan ochish
